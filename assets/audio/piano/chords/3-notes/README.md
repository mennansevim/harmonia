# 3 sesli piyano kayıtları

Kullanıcının birlikte çaldığı üç notanın hazır kayıtları bu klasöre gelecek.
Henüz ses yok; boş/sentetik WAV koyma. Kayıtlar gelince nota+oktav, akort,
format/süre/seviye ve kaynak/hak bilgilerini birlikte kontrol edeceğiz.
Dosya eklemek tek başına oynatma veya öğrenci değerlendirmesini açmaz.
